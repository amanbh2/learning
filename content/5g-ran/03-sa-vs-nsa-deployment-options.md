# SA vs NSA Deployment Options

## Overview
This note deep-dives into Standalone (SA) and Non-Standalone (NSA) 5G deployment options as defined by 3GPP. It covers all architecture options (Option 1–7), with focus on Option 3/3a/3x (EN-DC) and Option 2 (SA) — the two deployed in the real world. Understanding MN/SN roles, when each is used, and migration paths is critical for interviews.
