# 4G vs 5G — Key Differences

## Overview
This note provides a comprehensive comparison between LTE (4G) and NR (5G) across architecture, protocol stack, physical layer, and operational aspects. This is the **#1 most asked interview opener** — interviewers expect a structured, confident answer covering multiple dimensions.
